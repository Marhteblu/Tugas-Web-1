# Momen Bermain Roblox

Website satu halaman bertema game Roblox. Halaman ini dibuat menggunakan HTML, CSS, dan JavaScript dalam satu file HTML.

## Tampilan

![Screenshot halaman Momen Bermain Roblox](./screenshot.png)

## Fitur

- Menampilkan judul, tiga paragraf, dan desain dengan background gradasi.
- Tombol untuk menampilkan foto momen bermain dan waktu saat ini.
- Tombol untuk menutup tampilan foto.

## Menjalankan

Buka `index.html` di browser. Pastikan folder `Image` tetap berada di sebelah `index.html` agar foto dapat ditampilkan.
